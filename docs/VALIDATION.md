# 验证边界

v1.0.0 的自动化测试覆盖目标解析、状态机、互斥提交、独立停止、有界重试、未知结果复核、登录恢复和日志脱敏。

实站验收使用匿名化样本验证了以下行为：

- 正常页面操作能够进入提交与验证链；
- 一门课程成功后立即停止其 Worker，其他 Worker 可继续推进；
- 页面可识别的时间冲突会在提交前进入终态，不产生对应提交；
- HTTP 2xx 不会直接判定业务成功；
- 页面即时状态不明确时，Verifier 会重新载入并读取持久化已选状态；
- 运行结束后能够输出每门课程的独立状态和总结日志。

公开仓库不保存实站课程名称、教学班 ID、人数、账号信息、网络响应正文或个人日志。

仍未形成完整正常样本的场景包括满额、无资格、服务端限流和部分错误响应正文。遇到无法可靠分类的结果时，程序保守返回 `UNKNOWN`，不会伪造成功。
