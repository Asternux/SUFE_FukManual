# 验证范围与已知限制

## 已验证能力

v1.0.1 发布前通过：

- 30 项核心自动化测试；
- 26 项 Windows 交付层测试；
- TypeScript 严格构建；
- 标准 ZIP 与便携 ZIP 的独立解压启动测试；
- 便携包内 Playwright 本地依赖解析检查；
- Node.js 官方发行 ZIP 的 SHA-256 清单核验；
- 发布包隐私边界与禁止文件检查。

实站验收使用匿名化样本确认了以下行为：

- 正常页面操作能够进入提交与验证链；
- 一门课程成功后立即停止其 Worker，其他 Worker 可继续推进；
- 页面可识别的时间冲突会在提交前进入终态，不产生对应提交；
- HTTP 2xx 不会直接判定业务成功；
- 页面即时状态不明确时，Verifier 会重新载入并读取持久化已选状态；
- 运行结束后能够输出每门课程的独立状态和总结日志；
- 登录失效、单课程异常和未知结果不会让其他 Worker 盲目重复提交。

公开仓库和发行包不保存实站课程名称、教学班 ID、人数、账号信息、网络响应正文或个人日志。

## 已知限制

- 当前实现仅适配 `eams.sufe.edu.cn` 的已确认页面结构；
- 正式小白交付包仅支持 Windows 10/11 x64；
- 页面共享 Colorbox，因此不同课程的真实页面提交会通过共享锁串行进入页面事务；
- 满额、无资格、服务端限流和部分错误响应正文尚未形成完整正常业务样本；
- 学校页面改版、业务文本变化或认证流程变化可能需要更新解析逻辑；
- 人数未满不代表后端一定允许选课，最终资格和名额以学校系统为准。

遇到无法可靠分类的结果时，程序保守返回 `UNKNOWN`，先读取最终已选状态，不会伪造成功。
